# Escuela de Herramientas Computacionales en Astrofísica Solar 2026

¡Bienvenidas y bienvenidos!

Este repositorio reúne las presentaciones, cuadernos, datos, lecturas y recursos de la **Escuela de Herramientas Computacionales en Astrofísica Solar**, organizada por el Grupo de Astrofísica Solar (GoSA) del Observatorio Astronómico Nacional de la Universidad Nacional de Colombia.

La escuela está dirigida a estudiantes de pregrado y posgrado, jóvenes investigadores y personas interesadas en aprender a trabajar con observaciones, modelos y herramientas computacionales para estudiar el Sol.

## Información general

- **Fechas:** 1, 8, 15, 22 y 29 de octubre de 2026.
- **Frecuencia:** una sesión cada jueves.
- **Modalidad:** híbrida, con participación presencial en el Observatorio Astronómico Nacional y conexión virtual.
- **Costo:** gratuito.
- **Requisito recomendado:** conocimientos básicos de Python.
- **Página oficial:** [astronomiaoan.co/gosa/escuela.html](https://astronomiaoan.co/gosa/escuela.html)

## ¿Qué aprenderemos?

El programa combina conceptos físicos, demostraciones y actividades prácticas. A lo largo de las cinco sesiones se abordarán temas como:

- búsqueda, descarga y visualización de observaciones solares;
- archivos FITS, Astropy, SunPy y SAOImageDS9;
- imágenes de continuo, magnetogramas y Dopplergramas;
- manchas solares, flujos y movimientos en la superficie solar;
- magnetohidrodinámica, ondas y oscilaciones solares;
- simulaciones, partículas y computación de alto rendimiento;
- aplicaciones de aprendizaje automático y modelos multimodales en astronomía.

## Preparación del computador

Antes de las sesiones prácticas, consulte la [guía de instalación](02_Material_comun/Software_e_instalacion/Guia_instalacion_Escuela_Astrofisica_Solar.pdf). Allí encontrará instrucciones para Windows y Linux, incluyendo la instalación de Miniforge, Python, JupyterLab, Astropy, SunPy y SAOImageDS9.

Para descargar todo el material:

```bash
git clone git@github.com:Group-of-Solar-Astrophysics/Escuela-Astrofisica-Solar-2026.git
cd Escuela-Astrofisica-Solar-2026
```

También puede descargar el repositorio como archivo ZIP desde GitHub.
