# Escuela de Herramientas Computacionales en Astrofísica Solar 2026

Repositorio local para organizar los materiales de la escuela.

## Estructura

- `00_Organizacion`: comunicaciones, cronograma y plantillas oficiales.
- `01_Material_por_expositor`: espacio individual para el material de cada expositor.
- `02_Material_comun`: datos, lecturas y software compartidos entre varias sesiones.
- `03_Entregables_estudiantes`: ejercicios o resultados entregados por sesión.
- `04_Grabaciones`: grabaciones y archivos relacionados, cuando corresponda.

## Carpetas de cada expositor

Cada expositor dispone de las siguientes subcarpetas:

1. `01_Presentacion`: diapositivas en PDF, PPTX u otro formato.
2. `02_Notebooks`: cuadernos Jupyter y scripts utilizados en la sesión.
3. `03_Datos`: datos necesarios para las actividades prácticas.
4. `04_Lecturas`: artículos, notas y bibliografía recomendada.
5. `05_Recursos_adicionales`: enlaces, soluciones, imágenes u otros archivos.

## Convención para nombrar archivos

Utilizar nombres breves y descriptivos, sin espacios ni caracteres especiales:

`AAAA-MM-DD_expositor_descripcion_version.ext`

Ejemplos:

- `2026-10-01_juan-pablo_manchas-solares_v1.pdf`
- `2026-10-08_daniel_introduccion-sunpy_v1.ipynb`
- `2026-10-22_carlos_simulacion-particulas_v2.py`

## Recomendaciones

- Subir los materiales definitivos antes de la sesión correspondiente.
- No duplicar archivos; actualizar el número de versión cuando sea necesario.
- Comprimir conjuntos grandes de datos y añadir un archivo que explique su contenido.
- No incluir contraseñas, credenciales de servidores ni datos personales.
- Para archivos muy grandes, guardar un documento con el enlace y las instrucciones de acceso.
